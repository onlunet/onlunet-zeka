## 3. Cryptographic Approval Token Boundary

Approval tokens generated by human / authoritative controllers are protected by HMAC-SHA256:
- Token format: `v1.<planId>.<agentId>.<expiresAt>.<signature>`.
- Expiration: Strict millisecond-level timestamp validation.
- Replay Prevention: Single-use consumption tracking.
- Plan Binding: Tokens cannot be used for any plan other than the one specified in the cryptographic payload.
- Result: Tampered signatures, expired tokens, and cross-plan tokens are rejected 100% fail-closed.
