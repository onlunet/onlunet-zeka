  - `ProposalConflictType`: `SAME_TARGET_CONFLICT`, `DELETE_MODIFY_CONFLICT`, `MODIFY_DELETE_CONFLICT`, `DELETE_DELETE_CONFLICT`, `DUPLICATE_OPERATION_CONFLICT`, `INCOMPATIBLE_OPERATION_CONFLICT`, `DEPENDENCY_CONFLICT`, `AUTHORITY_CONFLICT`, `TASK_SCOPE_CONFLICT`.
  - `MAX_PROPOSALS_PER_PLAN = MAX_TEAM_SIZE` (= 5).
- **Core Engine: `aggregateAndReviewProposals`:**
  - Validates `taskId`, `orchestrationPlan`, team membership, and tenant/workspace boundaries.
  - Rejects malformed proposals, duplicate IDs, prototype pollution, path traversal, and command injection fail-closed.
  - Deterministically evaluates pairwise and target-level operation conflicts:
    - `MODIFY + MODIFY` / `CREATE + CREATE` -> `SAME_TARGET_CONFLICT`
    - `MODIFY + DELETE` / `DELETE + MODIFY` -> `DELETE_MODIFY_CONFLICT`
    - `DELETE + DELETE` -> `DELETE_DELETE_CONFLICT`
    - `CREATE + DELETE` -> `INCOMPATIBLE_OPERATION_CONFLICT`
    - Circular dependencies -> `DEPENDENCY_CONFLICT`
  - Resolves operation relationships:
    - `MODIFY + TEST` -> `MUTATION_REQUIRES_TEST`
    - `MODIFY + REVIEW` -> `MUTATION_REQUIRES_REVIEW`
  - Computes deterministic proposal summaries and deeply freezes the output.
